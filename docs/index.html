SwiftSheets

A pure Swift spreadsheet library with one format-neutral model and one codec per file format — XLSX, XLSM, CSV/TSV, ODS and Apple Numbers. Foundation and the Compression framework only; no external dependencies.

Source on GitHub · MIT · macOS 14+ / iOS 17+ · Swift 6.2+
