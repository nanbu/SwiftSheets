計測の条件

  • 日付: 2026-09-05、コミット: 714fe7f
  • 機械: Apple M2、メモリ 8 GB、26.6.2
  • ツールチェーン: swift-driver version: 1.148.6 Apple Swift version 6.3.3 (swiftlang-6.3.3.1.3 clang-2100.1.1.101)、release ビルド
  • 素材: synthetic: a label, five integers, three decimals and a Japanese category per row; one sheet; no formatting。合成データの数字は合成データの数字で、書式や図の多い実務のブックはこれより重い。
  • ピークメモリはプロセス生涯の最大値（ru_maxrss）。だから計測は 1 つずつ別のプロセスで走らせる。

自分の機械で測るには

scripts/bench.sh            # 100 万マス。Benchmarks/ を release で作り直して測り、docs/performance.json を書く
scripts/bench.sh 10000      # 小さめに
python3 scripts/build-performance-page.py --check   # このページと README の数字が出所と一致しているか
