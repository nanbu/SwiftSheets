計測の条件

  • 日付: 2026-09-05、コミット: a758803
  • 機械: Apple M2、メモリ 8 GB、26.6.2
  • ツールチェーン: swift-driver version: 1.148.6 Apple Swift version 6.3.3 (swiftlang-6.3.3.1.3 clang-2100.1.1.101)、release ビルド
  • 素材: synthetic, 100 columns: a label, five integers, three decimals and a Japanese category, repeated across the width with the numbers offset per block; the text columns past the first block draw on a vocabulary of fifty; one sheet; no formatting。合成データの数字は合成データの数字で、書式や図の多い実務のブックはこれより重い。
  • ピークメモリはプロセス生涯の最大値（ru_maxrss）。だから計測は 1 つずつ別のプロセスで走らせる。
  • 読みの値は、全載せで書いたファイル（アプリが書く形のファイル）を読んだ物。逐次で書いたファイルを読んだ値は「逐次で書いたファイル」の行に別に出す。

自分の機械で測るには

scripts/bench.sh                # 両方の段。Benchmarks/ を release で作り直して測り、docs/performance.json を書く
scripts/bench.sh --rows 10000   # 1 段だけ
python3 scripts/build-performance-page.py --check   # このページと README の数字が出所と一致しているか
